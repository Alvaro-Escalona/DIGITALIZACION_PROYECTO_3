# Transversor PDF Pro 📄🌍
*Advanced PDF document management with neural translation and structural preservation.*

## 🚀 Motivation
Transversor PDF Pro is designed for organizations that need to digitize and translate technical documentation without losing context. Unlike simple converters, this tool identifies **paragraphs, bullet points, and numbered lists**, ensuring the output remains professional and readable.

## ✨ Key Features
- **Structural Awareness:** Automatically detects and preserves document layout (lists, blocks, and spacing).
- **Batch Processing:** Handle multiple PDFs or entire folders simultaneously.
- **Multi-Language Engine:** Translation support for Spanish, English, French, Italian, Portuguese, German, and Chinese.
- **Hybrid Export:** Save your results as structured PDF or editable Word (.docx) files.
- **Efficiency:** Selective page translation to reduce processing time and API usage.

## 🛠️ Requirements & Setup
The project relies on the following key libraries:
- `customtkinter` (Modern UI)
- `pymupdf` (High-speed PDF engine)
- `deep-translator` (Neural Translation)
- `python-docx` & `reportlab` (Document generation)
